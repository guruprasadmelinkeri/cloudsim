To run CloudArchSim locally, open two terminal windows.

======================================================
TERMINAL 1: BACKEND (Python)
======================================================
1. Navigate to the backend directory:
   cd backend

2. Activate the virtual environment (it was already created):
   - Windows: .\venv\Scripts\activate
   - Linux/Mac: source venv/bin/activate

3. Start the FastAPI server:
   uvicorn main:app --reload

The backend will run on http://localhost:8000
(Swagger API docs at http://localhost:8000/docs)

======================================================
TERMINAL 2: FRONTEND (Next.js)
======================================================
1. Navigate to the frontend directory:
   cd frontend

2. Start the Next.js development server:
   npm run dev

The visual dashboard will be running at http://localhost:3000

======================================================
READY!
======================================================
Open http://localhost:3000 in your web browser.

Select a Scenario and an Architecture, then click "RUN SIMULATION".
